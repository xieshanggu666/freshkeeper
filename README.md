# 鲜知 FreshKeeper 🥬

家庭食材保质期决策助手：录入食材 → 自动计算该先吃谁 → 临期给出明确建议
（尽快食用 / 分装冷冻 / 建议丢弃）→ 用现有库存组合简单做法 → 所有修改与处理全程可追溯。

纯前端实现：**无需注册、无需服务器、数据只存在本机浏览器**。手机浏览器打开即可用，
支持拍照识别包装标签（识别结果需手动确认才会保存）。

## 快速开始

```bash
cd freshkeeper
npm start                 # 然后浏览器访问 http://localhost:8080
```

或直接双击打开 `index.html`（拍照识别需要联网加载一次 OCR 组件，其余功能离线可用）。

第一次使用可点右上角 ⚙️ → **载入演示数据**，立刻看到过期/临期/冷冻等各种状态。

## 主要功能

- **库存清单**：按处理优先级排序，红/橙/绿色标一眼看出“先处理谁”，可按过期、尽快、冷冻中等筛选。
- **明确建议**：点进食材可见“建议丢弃/尽快食用/冷冻中时钟暂停/品质下降”等结论、剩余天数和理由。
- **改变期限的记录**：已开封、放入冷冻、解冻、做熟、重新加热、移常温、吃完、丢弃——
  一键记录，期限立即重算（如开封后酸奶按 3 天计；复热不会“刷新”保质期）。
- **拍照录入**：拍包装标签自动识别品名、到期日、贮存条件，**回填表单由你确认**后才入库。
- **组合方案**：可勾选指定几样食材，系统按库存匹配家常做法；每个方案都写明
  「使用了哪些食材」和「做完后还有哪些需要尽快处理」，一键执行后自动写入处理记录。
- **全程追溯**：字段修改有旧值快照、期限事件可撤销（历史保留）、删除可恢复，另有完整操作流水。
- **数据自主**：一键导出/导入 JSON 备份，清空数据不留下任何东西。

设计原理（保质期时间轴模型、冷冻时钟暂停、事件溯源、方案打分）见 [DESIGN.md](DESIGN.md)。

## 目录结构

```
index.html          页面（库存 / 方案 / 追溯三视图）
css/styles.css      手机优先样式
js/rules.js         20 类食材的保质期规则库
js/engine.js        纯决策引擎：期限重放、五档状态、建议、优先级
js/planner.js       库存组合方案（8 个家常模板 + 丢弃/冷冻/复热处置）
js/ocr.js           拍照识别与标签文本解析
js/storage.js       本地存储、修订快照、审计流水
js/app.js           界面渲染与交互
test/               单元测试与端到端冒烟测试
```

> 安全提示：本应用的期限为家庭场景的保守建议，不替代食品包装标注；
> 肉禽水产蛋奶豆制品及剩菜过期后，即使外观正常也建议丢弃。
